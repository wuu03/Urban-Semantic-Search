## Introduction
**City of Water and Ink** is a Digital Humanities infrastructure that integrates 17th–18th century panoramic views of Venice with cadastral archives into a unified high-dimensional vector space.

Historically, Venice has been recorded through two disconnected media:

1. **Water (Visual):** Bird's-eye view maps (e.g., 1704 Mortier, 1675 Venetia).
2. **Ink (Textual):** Cadastral registers and archives (e.g., 1740 Catastici, 1808 Sommarioni).

This pipeline employs **Perception Encoder (PE)** and **MiniLM** to enable deep retrieval across visual textures, cross-lingual semantics, and spatial coordinates. It prepares the data for the frontend visualization platform by transforming raw assets into searchable vectors.

---

## Key Features
- **Multimodal Retrieval Support:** Prepares vectors for four search modes:
  - **T2I (Text-to-Image):** Search map tiles using text descriptions.
  - **I2I (Image-to-Image):** Find visually similar urban structures.
  - **I2T (Image-to-Text):** Retrieve documents based on map visuals.
  - **T2T (Text-to-Text):** Multilingual semantic search for abstract concepts.
- **AI-Powered Georeferencing:** Implements **Thin Plate Spline (TPS)** transformation to map non-linear historical maps to modern coordinate systems (WGS84).
- **Dual Embedding Strategy:** Generates both visual-aligned vectors (PE) and semantic vectors (MiniLM) for robust cross-modal understanding.
- **Hybrid Linkage:** Logically connects 1740 archives with 1808 records to enable diachronic analysis.

---

## System Architecture
The system consists of two parallel processing pipelines that feed into a **Qdrant** vector database.

### Visual Pipeline ("The Water Stream")
- **Slicing:** Uses a sliding-window approach (112px stride) to generate overlapping semantic units.
- **Feature Extraction:** Utilizes `PE-Core-B16-224` to extract 1024-dimensional texture features.
- **Georeferencing:** Maps pixel coordinates to Latitude/Longitude using GDAL and Ground Control Points (GCPs).

### Text Pipeline ("The Ink Stream")
- **Linearization:** Converts structured CSV/JSON metadata into natural language sentences (Semantic Anchors).
- **Dual Embedding:**
  - `text_vector` (384-d): Generated by `paraphrase-multilingual-MiniLM-L12-v2` for semantic search.
  - `pe_vector` (1024-d): Generated by PE Text Encoder for visual alignment.

## Installation

### 1. Start Vector Database

Run Qdrant using Docker:

```bash
docker run -p 6333:6333 qdrant/qdrant
```

### 2. Install Python Dependencies

```bash
conda create -n urbansearch python=3.11
conda activate urbansearch
pip install -r requirements.txt
```

---

## Usage

The entire ETL and Search pipeline is shown in `demo.ipynb`.

1. **Configure Paths:** Update `IMAGE_PATH` and `GCP_FILE` in the notebook to point to your local data.
2. **Run Visual Pipeline:** Execute cells to slice the map and extract PE features.
3. **Run Text Pipeline:** Execute cells to process 1740/1808 archives and generate embeddings.
4. **Ingest Data:** Upload vectors to Qdrant (Map Collection & Doc Collection).
5. **Search Demo:** Use the provided cells to run T2I, I2I, or T2T queries.
